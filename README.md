# Diario di lavoro

Progetto locale per una web app di registrazione e ricerca del lavoro svolto. La repository contiene al momento solo la mappa decisionale Wayfinder: nessuna funzione dell'app è stata implementata.

La mappa si trova in [`.scratch/diario-di-lavoro/map.md`](.scratch/diario-di-lavoro/map.md). Ogni ticket è un file separato nella cartella `issues/`.

La destinazione della mappa è una specifica verificata e pronta all'implementazione. Il prodotto finale richiesto resta una web app funzionante e testata su Chrome/macOS nelle condizioni aziendali effettive.
